정규 변화 동사

lernen처럼 어간에 현재형 인칭 어미를 붙이는 정규 동사의 기본 변화를 정리합니다.

규칙

정규 동사는 동사 원형에서 -en을 뺀 어간에 현재형 인칭 어미를 붙입니다. lernen의 어간은 lern- 입니다.

예시 · lernen

배우다
ich lerne
du lernst
er / sie / es lernt
wir lernen
ihr lernt
sie / Sie lernen

같은 규칙을 따르는 예시

machen 하다, 만들다 변화 보기 ＋
ich mache du machst er / sie / es macht wir machen ihr macht sie / Sie machen
wohnen 살다, 거주하다 변화 보기 ＋
ich wohne du wohnst er / sie / es wohnt wir wohnen ihr wohnt sie / Sie wohnen
spielen 놀다, 연주하다 변화 보기 ＋
ich spiele du spielst er / sie / es spielt wir spielen ihr spielt sie / Sie spielen
kaufen 사다 변화 보기 ＋
ich kaufe du kaufst er / sie / es kauft wir kaufen ihr kauft sie / Sie kaufen

어미 정리

기본 인칭 어미는 -e, -st, -t, -en, -t, -en입니다. 어간의 마지막 소리에 따라 발음을 쉽게 하기 위한 추가 규칙이 적용될 수 있습니다.
