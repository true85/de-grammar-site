-t, -d로 끝나는 동사

어간이 t 또는 d로 끝나는 동사의 현재형 변화와 연결 모음 e를 정리합니다.

규칙

동사의 어간이 t 또는 d로 끝나면 du, er/sie/es, ihr 형태에서 발음을 쉽게 하도록 어미 앞에 연결 모음 e를 넣습니다.

예시 · arbeiten

일하다
ich arbeite
du arbeitest
er / sie / es arbeitet
wir arbeiten
ihr arbeitet
sie / Sie arbeiten

같은 규칙을 따르는 예시

bilden 형성하다 변화 보기 ＋
ich bilde du bildest er / sie / es bildet wir bilden ihr bildet sie / Sie bilden
finden 찾다 변화 보기 ＋
ich finde du findest er / sie / es findet wir finden ihr findet sie / Sie finden
reden 말하다 변화 보기 ＋
ich rede du redest er / sie / es redet wir reden ihr redet sie / Sie reden
warten 기다리다 변화 보기 ＋
ich warte du wartest er / sie / es wartet wir warten ihr wartet sie / Sie warten
antworten 대답하다 변화 보기 ＋
ich antworte du antwortest er / sie / es antwortet wir antworten ihr antwortet sie / Sie antworten

주의할 점

어간이 -t 또는 -d로 보이더라도 발음 구조나 어간 변화 때문에 다른 형태가 나타날 수 있습니다. 규칙에서 벗어나거나 혼동하기 쉬운 동사는 일반 예시와 분리해 별도로 정리합니다.
